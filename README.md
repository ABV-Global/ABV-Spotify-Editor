# ABV Podcast — Editor v1.0

Versão de publicação baseada no arquivo aprovado `ABV_Podcast_Kit_Camadas_v1.zip`.

## Publicar

1. Crie um repositório no GitHub (por exemplo, `abv-podcast-editor`).
2. Envie `index.html`, `.nojekyll` e este `README.md` à raiz da branch `main`.
3. Em Settings > Pages > Build and deployment, escolha Deploy from a branch, branch `main`, pasta `/(root)` e Save.
4. Aguarde a publicação e use o link exibido em Settings > Pages.

O `index.html` é autossuficiente e contém os elementos gráficos da versão aprovada incorporados no próprio arquivo. Não depende de serviços externos.

Nota: um site GitHub Pages normalmente é público. Não inclua fotos privadas de pessoas no repositório; importe-as pelo editor quando necessário.
